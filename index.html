Web2Excel — Privacy Policy

Effective October 9, 2026 · Version 0.7.6 Release Candidate

Web2Excel is a Chrome extension that helps you visually select repeated content on webpages, build tables, and export CSV and Excel files. Support: nurzat03.10q@gmail.com.

What the extension accesses

Web2Excel requests access to ordinary HTTP and HTTPS websites when you install the extension. Its user-facing extraction interface inspects the active webpage's document structure to identify repeated items and extract fields you select. These fields may include text, product names, prices, links, image addresses and page URLs. Website access is required because the extension works across many websites rather than a predefined list. The extension does not perform unrestricted background crawling. Chrome lets you restrict or revoke site access from the extension's settings. Avoid collecting information from pages when you lack permission to use that information.

What is stored

Selected data, layouts, page records and collection history are stored locally in your browser through Chrome extension storage. This allows you to navigate pages, reopen the side panel, and reuse saved layouts. You can delete a collection, delete individual templates, or use Privacy & data controls → Delete all Web2Excel local data. These controls do not remove any CSV or Excel files already saved to your device.

Data sharing and network requests

Web2Excel does not require an account, use analytics or advertising trackers, or upload extracted datasets to a developer-controlled server. Selected data stays in your browser's local extension storage unless you choose to export it. Image previews may load from the original image-hosting websites. If direct image loading fails, the extension may make a background image request to the image host using its website permission; those hosts may receive ordinary network metadata such as your IP address. CSV and XLSX exports are generated locally.

Permissions

Web2Excel declares scripting to inject the visual selection tool into the current webpage, sidePanel to keep the workflow visible during selection, and storage to save templates and multi-page collections locally. Its HTTP/HTTPS host permissions let the extension identify the active webpage, read selected content and matching repeated items, continue across pages and switch to new websites without another site-access request each time. Chrome may display a warning about broad website access during installation. You can restrict or revoke site access under Chrome's extension settings; this may prevent extraction or image previews on restricted websites.

Data retention, security and choices

Locally saved extension data remains until you delete it, remove the extension, or Chrome deletes its storage. Data stays under your browser profile's security settings; shared computers and browser profiles should be treated accordingly. You can decline site access or image host access. Chrome also lets you revoke granted sites through the extension's settings.

Children and updates

Web2Excel is a general productivity tool and is not specifically intended for children. This policy may change if the extension's features or data handling change; significant changes will be disclosed as required.

Google API Limited Use

Use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
