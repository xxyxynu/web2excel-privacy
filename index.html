Web2Excel — Privacy Policy

Effective October 9, 2026 · Version 0.7.7 Release Candidate

Web2Excel is a Chrome extension that helps you visually select repeated content on webpages, build tables, and export CSV and Excel files. Support: nurzat03.10q@gmail.com.

What the extension accesses

Web2Excel processes content and structure from webpages you actively choose to extract from, such as product names, text, prices, images, links and page URLs. For a website you have not approved, you may need to click the blue W toolbar icon to identify the site, then approve one-time persistent access to that website. After approval, later visits and pages on that site can connect without another permission prompt. Web2Excel does not automatically crawl all websites in the background.

What is stored

Selected data, layouts, page records and collection history are stored locally in your browser through Chrome extension storage. This allows you to navigate pages, reopen the side panel, and reuse saved layouts. You can delete a collection, delete individual templates, or use Privacy & data controls → Delete all Web2Excel local data. These controls do not remove any CSV or Excel files already saved to your device.

Data sharing and network requests

Web2Excel does not require an account, use developer-controlled analytics or advertising services, or upload extracted datasets to a Web2Excel server. Selected data is processed and stored locally. Images may load from the original hosting websites, which can receive ordinary network metadata such as IP addresses. If direct previews fail, the extension can request optional access to an image-hosting domain for a background preview request; users can decline. CSV and Excel exports are generated locally.

Permissions

The activeTab permission helps identify a website after you click Web2Excel's toolbar icon. scripting enables visual element selection on an authorized webpage. sidePanel keeps the extraction interface open, and storage saves selected data and layouts locally. Optional HTTP/HTTPS host permissions are requested only when users choose to allow a particular website; accepted permission persists for subsequent visits, including manually navigated pages. Additional optional image-host access is offered if an external image server blocks direct previews. Users may review or revoke these site permissions from Chrome extension settings.

Data retention, security and choices

Locally saved extension data remains until you delete it, remove the extension, or Chrome deletes its storage. Data stays under your browser profile's security settings; shared computers and browser profiles should be treated accordingly. You can decline site access or image host access. Chrome also lets you revoke granted sites through the extension's settings.

Children and updates

Web2Excel is a general productivity tool and is not specifically intended for children. This policy may change if the extension's features or data handling change; significant changes will be disclosed as required.

Google API Limited Use

Use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
